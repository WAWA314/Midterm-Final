# Midterm-Final

โปรแกรม GUI รวมคะแนนและตัดเกรด นักศึกษา 20 คน วิชา Basic Computer Programming

## รายละเอียด
- **วิชา:** Basic Computer Programming
- **จำนวนนักศึกษา:** 20 คน
- **ระบบคำนวณ:** Midterm (40%) + Final (60%) = คะแนนรวม

## วิธีใช้งาน
1. เปิดโปรแกรมด้วยคำสั่ง `python "Midterm + Final.py"`
2. ป้อนคะแนน Midterm และ Final สำหร้บนักศึกษา
3. ระบบจะคำนวณคะแนนรวมและตัดเกรดอัตโนมัticamente
4. สามารถส่งออกไฟล์ CSV เพื่อบันทึกผล
